Arsitektur Sistem FoodSupply

Rust (Axum + Tokio + SQLx) PostgreSQL + PostGIS JWT + Argon2

1. Backend Rust Axum

Mengelola REST API berkinerja tinggi, asynchronous runtime Tokio, validasi schema serialisasi Serde, dan proteksi otentikasi berbasis JWT.

2. Database PostgreSQL & PostGIS

Mendukung 7 tabel relasional terstruktur (Users, Commodities, Markets, Stocks, Prices, Distributions, Notifications) serta query spasial GIS untuk perhitungan jarak pasar terdekat.
